# NutriBox — Healthy Meal Prep

Website company profile sederhana untuk contoh perusahaan katering sehat dan layanan meal prep.

## Struktur folder

```text
nutribox-meal-prep/
├── index.html       # Halaman Home
├── about.html       # Halaman About Us
├── css/
│   └── style.css    # Seluruh gaya dan layout responsif
├── js/
│   └── script.js    # Menu mobile, navigasi anchor, dan tahun footer
└── README.md
```

## Cara menjalankan di VS Code

1. Ekstrak folder proyek.
2. Buka folder `nutribox-meal-prep` menggunakan Visual Studio Code.
3. Buka `index.html` di browser. Bisa juga menggunakan ekstensi **Live Server** di VS Code, lalu klik kanan `index.html` dan pilih **Open with Live Server**.
4. Gunakan menu **About Us** untuk membuka halaman kedua. Link Paket Menu, Keunggulan, dan Kontak menuju bagian terkait di halaman Home.

## Catatan penyesuaian

- Nama brand, deskripsi layanan, harga contoh, dan alamat email di website adalah konten contoh yang dapat diganti.
- Foto dan font dimuat dari layanan eksternal, sehingga koneksi internet diperlukan untuk menampilkan aset tersebut.
- Tombol konsultasi email menggunakan alamat contoh `halo@nutribox.id`; ganti dengan alamat bisnis yang sebenarnya sebelum website dipublikasikan.
- Website ini adalah front-end statis. Formulir pemesanan, pembayaran, dan penyimpanan data belum diintegrasikan.
